# Obsidian Synology Sync

[![Release](https://github.com/my3rs/obsidian-synology-sync/actions/workflows/release.yml/badge.svg)](https://github.com/my3rs/obsidian-synology-sync/actions/workflows/release.yml)

[English](README.md)

通过群晖官方 Drive API 将您的 Obsidian 笔记库与群晖 (Synology) NAS 进行同步。此插件提供了一种安全可靠的方式，将您的 Obsidian 笔记直接备份和同步到群晖中，而无需依赖任何第三方云服务中转。

### 功能特点

- 基于**群晖官方 WebAPI**（Synology Drive API）直接打通，更加原生、官方且安全。
- 支持双向同步、仅上传和仅下载模式。
- 采用直接鉴权，账号密码仅用于在本地直接请求您的群晖 NAS 进行官方登录，全程无第三方数据收集。
- 多语言支持（英文和中文）。

### 配置指南

1. 进入 "Synology Sync" 设置选项卡。
2. 输入您的群晖 NAS 地址（例如：`https://your-nas-ip:5001`）。
3. 输入您的群晖用户名和密码。
4. 测试连接并开始同步！

详细使用说明见[同步与恢复指南](docs/sync-guide-zh.md)，构建和测试方法见[开发指南](docs/development-zh.md)。
