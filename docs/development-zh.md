# 开发与验证

[English](development.md) · [项目介绍](../README-zh.md)

运行 `npm test`、`npm run build`、`npm run lint`。自动测试使用实际的差异计算、同步引擎、事务模块和 API 客户端，文件系统及网络使用隔离替身。覆盖复制状态、双端竞争、冲突收敛、重复同步、删除/提交/保存失败、分页及 HTTP 200 业务错误。

发布前还需在真实群晖上验证独占创建和索引可见性，再使用两个桌面端与一个移动端，在临时库验证休眠恢复及崩溃恢复。这些集成验收不能用模拟测试代替，应在每次发布时单独记录验收结果。

文本替换使用 Obsidian 的 [`Vault.process()` 原子更新接口](https://docs.obsidian.md/Plugins/Vault)，在落盘前再次拒绝覆盖刚发生的编辑。二进制附件有写入前检查，但没有对应的原子比较替换接口；同步期间同时由外部程序编辑附件仍属于需真机验证的边界。
